# kubatura-ru.github.io

Сайт разработчика на GitHub Pages: https://kubatura-ru.github.io/

Нужен магазинам и рекламной сети: у политики конфиденциальности должен
быть постоянный адрес, открытый без входа, а `app-ads.txt` (если сеть его
попросит) работает только в корне домена — поэтому это репозиторий
`<владелец>.github.io`, а не папка в репозитории игры.

    index.html            список приложений и связь
    palka/privacy.html    политика «Палки»
    app-ads.txt           кто вправе продавать рекламу в приложениях

`palka/privacy.html` — копия `palka/app/assets/privacy.html` из
репозитория игры, байт в байт: в игре и на сайте должна быть одна и та же
редакция. Меняется политика в игре — сюда кладётся тот же файл.
`.nojekyll` выключает обработку Jekyll: страницы готовые, собирать нечего.

`app-ads.txt` — файл из кабинета Рекламной сети Яндекса как есть, без
правок (16.11.2026): своя строка `yandex.com, 332279085, DIRECT`, где
332279085 — номер аккаунта в сети, а не приложения, и строки партнёров,
через которых Яндекс продаёт показы. Рекламодатели сверяют по нему, что
показ в палке продаёт тот, кому разрешено; без файла часть из них
показы не покупает (оценка). Яндекс поменяет список — заменить файл
целиком новым из кабинета. Находят его по сайту разработчика в карточке
магазина, поэтому в RuStore сайтом указан https://kubatura-ru.github.io/.
